# Sistema da Cantina do Grêmio

Projeto React criado com Vite.

## Rodar localmente

```bash
npm install
npm run dev
```

## Publicar na Vercel

1. Envie esta pasta para um repositório no GitHub.
2. Entre em https://vercel.com.
3. Clique em Add New > Project.
4. Escolha o repositório.
5. Clique em Deploy.
